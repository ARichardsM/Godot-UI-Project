# Godot UI Project
 
## Summary

The Godot UI Project is a project focused on integrating previous work, including the Character Tracker and SFML Tabletop projects, to create a user interface system. By leveraging the Godot UI system, C#, and R, the project seeks to help determine group compatability via data visualization with intuitive, efficient UI designs. With a primary focus on Godot’s control nodes, this effort aims to deepen expertise in interactive system design while advancing previous projects.

## Overview

| File                       | Description                                                                   |
|----------------------------|-------------------------------------------------------------------------------|
| Data\Data.csv              | User input data, generated by the UI to allow for the R script.               |
|----------------------------|-------------------------------------------------------------------------------|
| Scenes\CharacterMenu.tscn  | Godot scene file for the entity creation screen.                              |
| Scenes\FileMenu.tscn       | Godot scene file for the file reading and writing screen.                     |
| Scenes\MainMenu.tscn       | Godot scene file for the initial screen.                                      |
|----------------------------|-------------------------------------------------------------------------------|
| Scripts\CharacterScript.cs | C# script used by `CharacterMenu.tscn`.                                       |
| Scripts\FileScript.cs      | C# script used by `FileMenu.tscn`.                                            |
| Scripts\MainScript.cs      | C# script used by `MainMenu.tscn`.                                            |
| Scripts\ScaleSelection.cs  | C# script used by `ScaleSelection.tscn`.                                      |
| Scripts\Global.cs          | C# script containing global autoloaded functions.                             |
|----------------------------|-------------------------------------------------------------------------------|
| ButtonTheme.tres           | Godot resource file containing the button design for an unselected button.    |
| ButtonTheme2.tres          | Godot resource file containing the button design for a selected button.       |
|----------------------------|-------------------------------------------------------------------------------|
| Button.tscn                | Godot scene file handling a singular button.                                  |
| ScaleSelection.tscn        | Godot scene file handling the selection buttons used by `CharacterMenu.tscn`. |
|----------------------------|-------------------------------------------------------------------------------|
| RFunction.R                | R script for data visualization and analysis.                                 |
